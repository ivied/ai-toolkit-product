# Mastodon Marketing Strategy

## Why Mastodon
- No algorithmic shadowbanning (chronological feeds)
- Tech-savvy audience (developers, FOSS enthusiasts)
- Hashtag discovery works well (unlike Twitter/Reddit for new accounts)
- No karma requirements, no spam filters blocking links
- Community values open source — aligns with our Codeberg blog approach

## Instance Selection
Best instances for tech/dev content:
1. **fosstodon.org** — FOSS community, perfect for dev tools (~50K users)
2. **hachyderm.io** — tech professionals (~50K users)
3. **mastodon.social** — general, largest (~2M users)
4. **techhub.social** — technology focused

**Recommendation:** fosstodon.org (best alignment with open source dev tools)

## Content Plan (first 2 weeks)

### Week 1: Establish Presence
- Day 1: Profile setup (bio: Python developer, automation, AI tools)
- Day 1: Introduction post (#introduction tag — Mastodon tradition)
- Day 2: Share blog article "5 Python Scripts Every Developer Should Have" with value excerpt
- Day 3: Share a useful Python tip (standalone, no link)
- Day 4: Share RAG pipeline article with technical insight
- Day 5: Engage with others' posts (boost, reply to Python/automation content)
- Day 6: Share Telegram bot tutorial
- Day 7: Python tip or code snippet (no link)

### Week 2: Build Engagement
- Day 8: Share web scraping guide
- Day 9: Thread about automation patterns (standalone value)
- Day 10: Share API integration article
- Day 11: Reply to discussions, offer help
- Day 12: Share "what I learned building 14 Apify actors" (story post)
- Day 13: Engage with #Python #Automation hashtag communities
- Day 14: Soft CTA — mention toolkit availability

### Hashtags to Use
- #Python #Automation #WebScraping #AI #RAG
- #FOSS #OpenSource #Developer #Coding
- #SideProject #IndieHacker #BuildInPublic

## Content Ratio
- 70% value (tips, code snippets, tutorials, engagement)
- 20% blog articles (with genuine value in the post text)
- 10% direct promotion (toolkit, services)
