# 💼 Business Prompts

## Competitor Analysis

```
Analyze [company/product] as a competitor:

1. Product/service overview
2. Pricing model and tiers
3. Target audience
4. Key strengths (what they do well)
5. Key weaknesses (gaps, complaints)
6. Market positioning
7. Recent moves (funding, launches, pivots)
8. Opportunities for differentiation

Sources to check: G2, Capterra, ProductHunt, Crunchbase, Twitter mentions.
```

## Pitch Deck Outline

```
Create a pitch deck outline for: [describe startup/product]

Slides:
1. Title + one-liner
2. Problem (with data)
3. Solution (with demo screenshot description)
4. Market size (TAM/SAM/SOM)
5. Business model
6. Traction / metrics
7. Competition (positioning map)
8. Team
9. Financials (3-year projection)
10. Ask (funding amount + use of funds)

For each slide: provide the key message, supporting data points,
and speaker notes.
```

## Pricing Strategy

```
Help me price [product/service]:

Context:
- Target customer: [describe]
- Competitors charge: [price range]
- My costs: [approximate]
- Current stage: [startup/growth/mature]

Analyze:
1. Value-based pricing calculation
2. Cost-plus pricing floor
3. Competitive positioning options
4. Recommended tier structure (good/better/best)
5. Psychological pricing tactics
6. When to raise prices
```

## Customer Interview Script

```
Create a customer interview script for [product/feature]:

Goal: [what you want to learn]
Duration: 30 minutes

Include:
1. Warm-up questions (2-3 min)
2. Problem exploration (10 min)
3. Current solution / workarounds (5 min)
4. Solution validation (10 min)
5. Willingness to pay (3 min)
6. Wrap-up

Rules:
- No leading questions
- Open-ended format
- Focus on behaviors, not opinions
- Include follow-up probes for each question
```
