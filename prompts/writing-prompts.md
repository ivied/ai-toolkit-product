# ✍️ Writing & Content Prompts

## Blog Post Generator

```
Write a blog post about: [topic]

Requirements:
- Length: ~1500 words
- Tone: [professional/casual/technical]
- Audience: [describe target reader]
- Include: intro hook, 3-5 sections with headers, practical examples, conclusion with CTA
- SEO: naturally include these keywords: [list]
- Add a TL;DR at the top
```

## Email Sequence

```
Create a 5-email nurture sequence for [product/service]:

Audience: [describe]
Goal: [trial signup / demo booking / purchase]

For each email:
- Subject line (+ A/B variant)
- Preview text
- Body (200-300 words)
- CTA button text
- Send timing (days after signup)

Principles: value-first, no hard sell until email 4, story-driven.
```

## Social Media Content Calendar

```
Create a 2-week social media content plan for [brand/product]:

Platforms: [Twitter, LinkedIn, Instagram]
Posting frequency: [per platform]
Brand voice: [describe]
Goals: [awareness / engagement / conversions]

For each post:
- Platform
- Date/time
- Content (full text, within platform limits)
- Hashtags
- Visual description (for designer)
- CTA or engagement hook

Mix: 40% educational, 30% engagement, 20% promotional, 10% behind-the-scenes
```

## Technical Documentation

```
Write documentation for: [API/library/feature]

Structure:
1. Overview (what it does, when to use it)
2. Quick Start (get running in 5 minutes)
3. Installation
4. Configuration
5. API Reference (each method/endpoint)
6. Examples (common use cases)
7. Troubleshooting (common errors)
8. FAQ

Style: clear, concise, code-heavy. Use callout boxes for warnings/tips.
```

## Rewrite for Tone

```
Rewrite this text in [target tone] voice:

Original:
[paste text]

Tone guidelines:
- Professional: clear, authoritative, no slang
- Casual: conversational, contractions OK, personality
- Academic: formal, citations-ready, precise terminology
- Sales: benefit-focused, urgency, social proof
- Technical: accurate, specific, code examples

Keep the same information and structure. Just change the voice.
```
