# 📊 Analysis & Research Prompts

## Data Analysis

```
Analyze this dataset:

[paste data or describe it]

Provide:
1. Summary statistics (mean, median, distribution)
2. Key patterns and trends
3. Outliers and anomalies
4. Correlations between variables
5. Actionable insights (what should we do?)
6. Visualization suggestions (what charts to make)

Present findings in order of business impact.
```

## Market Research

```
Research the [industry/niche] market:

1. Market size and growth rate (with sources)
2. Key players and market share
3. Customer segments and their needs
4. Pricing landscape
5. Technology trends
6. Regulatory considerations
7. Entry barriers
8. Opportunities for a new entrant

Focus on actionable intelligence, not general knowledge.
Cite specific numbers where possible.
```

## Root Cause Analysis

```
Help me find the root cause of: [describe problem]

Context:
- When it started: [date/time]
- What changed: [recent changes]
- Impact: [who/what is affected]
- What we've tried: [attempted fixes]

Apply:
1. 5 Whys analysis
2. Fishbone diagram (categories: People, Process, Technology, Environment)
3. Timeline of events
4. Hypothesis ranking (likelihood × impact)
5. Recommended investigation steps
6. Preventive measures
```

## Decision Framework

```
Help me decide between: [option A] vs [option B] (vs [option C])

Context: [situation]
Constraints: [budget, time, resources]
Priorities: [what matters most]

Analyze using:
1. Pros/cons for each option
2. Weighted scoring (criteria × importance)
3. Risk assessment
4. Reversibility (how hard to undo?)
5. Second-order effects
6. Recommendation with confidence level
```

## Research Summary

```
Summarize the current state of research on [topic]:

Include:
1. Key findings from recent studies (2023-2026)
2. Areas of consensus
3. Active debates / open questions
4. Practical applications
5. Gaps in current knowledge
6. Recommended reading (3-5 key papers/articles)

Target audience: [technical/general/executive]
Max length: [words]
```
